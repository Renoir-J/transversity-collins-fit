# Complete geometry jobs for the conditional BaBar diagnostic

The [prospective operational contract](../config/historical-sia-job-contract.json) decomposes the existing conditional 72-amplitude diagnostic into 36 complete geometry jobs and a complete global ledger. It is declared before the new implementation or numerical candidates. Publishing a plan does not start a physical calculation or approve a fitting gate.

The numerical parent remains `6c88d12516074889f49a0dfeae456d6cc63491b4`. All 302 inherited files and its numerical fingerprint must remain unchanged. The additive adapter has its own commit and complete raw-file inventory. Numerical workers load the explicit frozen Julia project, rather than silently changing its source identity.

The two source rows associated with one exact `(z1,z2,Q2)` geometry share native preparation. Their UL/UC angular scalars, measured fields, errors and locators remain distinct. The source request remains the full ordered 72-point request. Fresh source reconstruction writes below the new run; the legacy verifier that creates temporary siblings of its input is not called. Interrupted original SIA reports remain immutable evidence and supply no completed jobs or gates to this family.

The equations and scientific targets remain those of [the parent integral contract](../config/historical-sia-integral-contract.json). The diagnostic uses the literal rounded parameters, conditional source-literal Q2, fixed z means and a uniform finite qT window. It integrates absolute charge-pair yields before forming UL/UC ratios, preserving the momentum Jacobian and source angular factors. Full experimental bin or acceptance integration is still unvalidated.

Each geometry retains every declared momentum order. A separate selector chooses the first common accepted order from **all 72** outputs at a given native level and finite bound. Choosing an independently convenient order for each geometry would change the inherited global selection and is forbidden. All 36 native1/2/3 jobs are required before deciding whether all 36 native4 jobs are necessary. One common native level is then used for every finite-tail and reference job.

Finite-tail/reference jobs cover every geometry. The same three source-selected geometries retain the parent's inward all13 gradient/HVP checks. Shared prepared rows are explicit: scalar adaptive integration is not independent evolution, and three derivative geometries are not an all72 production derivative certificate.

Every complete job consists of a Julia producer and a fresh Julia saved-record auditor. The initial sentinel, exact commands, both resource records, complete source/input/output hashes and effective/raw exit outcomes are retained. A completion marker without current complete provenance and arithmetic is insufficient. Occupied failed or interrupted folders are preserved and rejected.

The final independent reader requires the entire ledger, common selections, source order and all saved checks. Only a complete reconstructed diagnostic and fresh cached-workflow verification can produce the 72-row comparison and source-binned figures. No likelihood, chi2, optimization or physical extraction is introduced.

The prospective resource limits apply to each complete producer/auditor pair and are not throughput measurements. Physical dispatch waits for a frozen, reviewed implementation and for the existing SIDIS continuation to release the host. This work does not modify that running job or retry the old monolithic cloud command with the same budget.

Missing original code, failed paper-center moments, source/acceptance assumptions, covariance/overlap and the complete B0-B4/V1 uncertainty/publication scope remain open.

## Current implementation scope

The source-only planner and Julia complete72 arithmetic reducers are implemented. Numerical geometry producers, independent per-job auditors, the complete execution ledger and physical cached products remain pending. This command cannot dispatch Julia numerical jobs:

```sh
python scripts/plan_sia_geometry_jobs.py plan \
  --frozen /absolute/path/to/frozen-sia-checkout \
  --request /absolute/path/to/source-request.json \
  --output runs/sia-geometry-source-plan/attempt-1
python scripts/plan_sia_geometry_jobs.py verify \
  runs/sia-geometry-source-plan/attempt-1/plan.json \
  --expected-sha256 EXTERNALLY_RETAINED_PLAN_SHA256
julia --project=numerics numerics/test/sia_geometry_selection_tests.jl
```

Planning requires committed, unchanged raw Git blobs and replays all72 source rows below a fresh new directory. Verification requires an externally retained hash and a fresh source replay below that same directory. Neither a rehashed forged plan nor a successful source replay can authorize a physical job. The Julia reducers retain every declared momentum order, preserve all72 source identities, recompute absolute yields/category/ratio checks and apply the global common-order/native/finite-tail rules. Their tests use explicitly synthetic arithmetic and compare the packed values and error operands with the inherited numerical helpers; they are not physical predictions or an independent global job audit.
