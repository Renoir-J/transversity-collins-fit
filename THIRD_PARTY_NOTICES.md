# Third-party sources

Pinned source repositories and commits are listed in `references/source-inventory.json`. They are fetched into ignored `external/`; their source and licenses are not replaced by this project's terms. No third-party implementation is vendored into the new numerical package.

The project-owned fixed-operator ABI bridge is independent code. It is not the author-modified HOPPET from KPSY15. FeynFacet symbolic calculations retain their original toolchain and attribution. JAM Gaussian/log-log code and KPSY CSS predictions remain separate benchmark families.

The small closure fixtures were generated for software verification and contain no experimental measurements. A public software license for project-owned code has not yet been selected.
